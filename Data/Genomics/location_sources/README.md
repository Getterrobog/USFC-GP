# Publication and GEOME location evidence

Start with [location_provenance.csv](../../../Output/Genomics/location_provenance.csv)
to trace a genetic sample's assigned location or collection year. This directory
holds its inspectable source material, not sequencing reads.

| Files | Purpose |
| --- | --- |
| `source_manifest.csv` | Source IDs, download and landing URLs, publication DOIs, UTC retrieval times and SHA256 hashes of the six original publication/repository files |
| `bco854878_samples.csv`, `bco854878_description.pdf` | BCO-DMO silverside sample/accession/location/date table and dataset description, including library-quality exclusions |
| `fundulus_evad123.xml`, `fundulus_evad123_supp.zip` | Full article and original supplement archive for the 2023 Fundulus study |
| `atherino_evac111.xml`, `atherino_evac111_supp.zip` | Full article and original supplement archive for the 2022 Atherinomorus study |
| `*_Table*.csv` | Extracted spreadsheet values; `source_member` and `source_row` locate the original workbook, worksheet and row |
| `geome_records.csv` | GEOME sample/event/tissue metadata, record IDs and query URLs; discovery leads, not verified WGS matches |
| `geome_searches.csv` | Search outcome for every one of the 80 atlas species |
| `queries.csv` | Request URLs, raw cache paths, timestamps and response hashes for these sources |

All files except this README are generated by
`python3 Scripts/genomics_location_io.py` (offline), also invoked by the R inventory
build. `--download` permits missing-cache retrieval. Raw response snapshots are
retained under `../raw/geome/` and `../raw/location_publications/`. The location
helper reuses pinned snapshots; the main build's `--refresh` currently refreshes
ENA/NCBI only. Do not edit generated evidence files to curate an assignment.

Source registration and manually transcribed article-site coordinates live in
`config/genomics_location_sources.json` and `config/genomics_publication_sites.csv`.
The latter retains original DMS strings, article section and caveats. Exact sample
joins, reconciliation and exclusions are implemented in base R in
`Scripts/genomics_locations.R`. See [methods](../../../docs/genomics_inventory.md)
for the matching rules, conflicts and remaining publication-review leads.

Shared population-site coordinates are approximate for individual fish. No
numeric uncertainty is supplied unless reported by a source. Collection years
are never inferred from a publication date, permit year or sequencing filename.
The current GEOME results have no explicit BioSample links and are not attached
to genomic samples merely because species names match.
