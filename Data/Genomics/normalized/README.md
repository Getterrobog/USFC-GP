# Tabular archive metadata before R processing

Generated by `Scripts/genomics_archive_io.py` from [cached responses](../raw/README.md).
Do not edit by hand. All cells initially remain strings, including accessions.

- `taxa.csv`: one row per project species, archive taxon ID/name, name-resolution
  evidence, query status, and result counts. Unresolved names remain explicit.
- `runs.csv`: one row per genomic sequencing run; preserves library strategy,
  sample/study/experiment accessions, yield, collection fields, and read links.
- `assemblies.csv`: assembly accessions, paired GenBank/RefSeq accessions,
  annotation evidence, assembly statistics, BioSample and BioProject links.
- `sample_attributes.csv`: long-form sample attributes from ENA XML and NCBI
  assembly BioSample descriptors, with source URLs. Differing values are retained.
- `sample_retrieval.csv`: whether each requested sample was returned by ENA XML.
  Assembly BioSample descriptors and run fields can still supply metadata when
  a sample XML record is unavailable.
- `studies.csv`: project descriptions and linked publication identifiers.
- `queries.csv`: request manifest for the exact responses used.
- `acquisition_errors.csv`: failed species queries. A complete build requires an
  empty error table; failures are never converted to biological absences.

The corresponding [output tables](../../../Output/Genomics/README.md) add the R
scientific classifications and screening decisions.
