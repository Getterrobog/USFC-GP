For a newcomer, read the [proposal](../background/one_page_proposal.txt), browse
the [atlas](../Output/SamplingAtlas/README.md), then read the selection workflow
and protocol. The workflow describes implemented analyses; the protocol also
describes future work and pending evidence. The repository review is a dated
assessment, not a live status dashboard.

Saved outputs have their own [directory guides](../Output/README.md). Their
configuration and checksum manifests describe the run that produced them; counts
quoted in method documents should be interpreted in that snapshot's context.
