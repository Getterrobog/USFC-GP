# Legacy figures

These saved histograms and species-table PDFs belong to the earlier exploratory
museum-processing workflow. They are retained for context and are not the current
geographic sampling atlas or species-selection result.

For current annual geographic PNGs and GIFs, use the
[atlas viewer](../SamplingAtlas/README.md). For the historical species-by-site
comparison, use [SpeciesSelection](../SpeciesSelection/README.md).

See the [repository review](../../docs/repository_review.md) before interpreting
legacy counts or spatial groups. No current rebuild command is implied for these
historical artifacts merely because they are present here.
